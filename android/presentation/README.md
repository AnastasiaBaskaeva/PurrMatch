# Компоненты PurrMatch

Источник: [Figma, «Ии макет», 264:5](https://www.figma.com/design/X7Kp2gmSu5nTt3mpFwV7d0/neRacov-meet?node-id=264-5).
Исходники находятся в `src/main/java/com/purrmatch/presentation/components`.

## Использование

Оборачивайте компоненты в `Theme`. Данные и обработчики приходят
через параметры; компонентов, зависящих от ViewModel, навигации или сети, нет.
`Modifier` управляет внешними размерами и отступами. Системные insets
обрабатывает экран, а не кнопки, панели или карточки.

```kotlin
Theme {
    Background(Modifier.fillMaxSize()) {
        Button(
            text = "Показать анкеты",
            onClick = onApplyFilters,
            modifier = Modifier.fillMaxWidth(),
        )
    }
}
```

Поля и переключатели управляются снаружи. Для пароля передавайте `visible`
и `onVisibilityChange`. `SelectField` позволяет открыть свой
bottom sheet; `DropdownField` содержит готовое выпадающее меню.
Карточки принимают `Painter`; пустые фото в строках макета сохранены как
пустые слоты и заполняются при передаче фотографии.

У `SwipeCard` порог выбора составляет четверть ширины; короткий
жест возвращает карточку. Дополнительные действия доступны через обычные
кнопки/обработчики экрана. `SwipeCardFrame` воспроизводит
промежуточное состояние без жестов.

## Ресурсы и размеры

- Поля: высота 62 dp, многострочные 100 dp, радиус 17 dp.
- Основные кнопки: 54 dp, радиус 20 dp, нижняя тень 5 dp.
- Теги: 30 dp, чипы выбора: 39 dp; радиус 12 dp.
- Карточка списка: 106 dp, слот фото 84 dp, радиус 21 dp.
- Большая карточка: радиус 28 dp, фото с отношением сторон 332:365.
- Top bar: 68 dp. Bottom bar: 81 dp, радиус 25 dp.
- Диалог: горизонтальный отступ 24 dp, радиус 28 dp, внутренний отступ 22 dp.

Рамка телефона, подписи экранов и нарисованный статус-бар из Figma
относятся к оформлению макета и в компоненты не входят.
Тёмная палитра в макете не задана; библиотека воспроизводит светлую тему.
Android и браузер используют разные растеризаторы текста и теней.

SVG иконок конвертированы штатным Android SDK `Svg2Vector`; оригиналы сохранены
рядом с проектом. В `res/drawable` находятся 20 иконок с именами `ic_*`;
лапка, удаление и контур профиля переиспользуются в разных размерах и цветах.
Цвет одноцветной иконки задаётся параметром `Icon(..., tint = ...)`,
размер — через `Modifier.size`. Варианты с другой заливкой сохранены отдельно.
Соответствие SVG и Android-ресурсов записано в `design/figma/assets.json`
относительно корня Android-проекта.
Две составные статические иллюстрации экспортированы в SVG
отдельно от экранов и растрированы с прозрачностью в четырёхкратном размере.
Шрифты взяты из Google Fonts, статические начертания
получены из variable-font оригиналов, лицензии OFL находятся в
`src/main/assets`. Временных URL Figma в runtime-коде нет.
Оригинальные фото макета находятся в `src/main/res/drawable-nodpi` и используются экранами. Каталог компонентов находится в `src/debug`.

## Просмотр и проверки

Откройте `src/debug/java/.../components/preview` в Android Studio:
Preview сгруппированы по кнопкам, полям, карточкам, навигации и состояниям.
Экраны находятся в пакетах `auth`, `browse`, `favorites`, `profile`, `filters`
и `listing` внутри `src/main/java/com/purrmatch/presentation`. Рядом с кодом находятся
именованные Preview всех 18 экранов и состояний размером 376×803 dp.
Они используют `App`, поэтому включают тему, фон и навигационные панели.
Навигация приложения и превью диалогов находятся в `App.kt`,
общая разметка экранов — в `components/ScreenLayout.kt`.
Модуль `:app` открывает экраны; каталог доступен через extra `sample`.
[Все экраны, маршруты и сценарии](../README.md).

```sh
./gradlew :app:assembleDebug :presentation:assembleRelease
./gradlew :app:lintDebug :presentation:lintDebug
ANDROID_SERIAL=<device> ./gradlew :presentation:connectedDebugAndroidTest
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell am start -n com.purrmatch.android/.MainActivity
adb shell am start -n com.purrmatch.android/.MainActivity --es sample home
```

UI-тесты проверяют ввод, пароль, выбор, switch, недоступную кнопку,
вложенные действия карточки, свайп, подтверждение, dropdown, лимит фото и галерею.
Тест рендера сохраняет 14 PNG при размере 376×803 через
`additionalTestOutputDir`; Gradle забирает их в
`build/outputs/connected_android_test_additional_output`.
Это снимки для визуального сравнения, без автоматического pixel-diff.
